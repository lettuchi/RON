# 嘘つきの糸 — *Usotsuki no Ito*
### "The Liar's String" — Ending Song (Kaoru's POV)

- **Game:** Ryoko Owari Nights
- **Use:** Ending / credits theme (planned: `game/audio/bgm/ending_song.mp3`)
- **Style:** Slow noir piano ballad with pulse/energy; smoky, intimate
- **Vocal:** male lead, low / velvety / gravitas (Kaoru's POV — mirrors the "Jax Meridian" deep-storyteller direction)
- **Register:** Kaoru uses 俺 (*ore*) for himself and お前 (*omae*) for Toa
- **Themes / motifs:** the red string of fate reframed as **shibari knots** (縛る・結び目); **ink & the magistrate's seal** (墨・朱肉・判・捺す) with the **vermillion seal-ink = the red of fate**; possession masking buried tenderness; whether he loves her is left deliberately **ambiguous**.
- **Counterpart to the opening song** 「嘘の街の赤い糸」 (Toa's POV). Her thesis: *love doesn't need to be returned to be real.* His answer: *I don't know how to return it — and I'll never let the string be cut.*

---

*The ending is deliberately ambiguous: 言葉にすれば嘘になる ("spoken, it becomes a lie") reads either as a feeling too true to risk naming in a city of lies, or as an admission that there is nothing real to name. He answers with the shibari knot, never the word. English lines are singable/poetic rather than strictly literal; romaji uses macrons for long vowels (ō, ū).*
